# MatDash UI 0.2.0 Release Notes

MatDash UI 0.2.0 is the first feature release that treats the project as a broader application design system rather than only a dashboard kit.

## Release focus

- Rich application controls
- Searchable selection patterns
- Date and calendar primitives
- Command and context actions
- Nested navigation
- Workflow/status visualization
- Stronger data-table behavior
- Expanded chart primitives
- Component discovery through an interactive lab

## New components

`Accordion`, `Popover`, `Calendar`, `DatePicker`, `Combobox`, `CommandPalette`, `ContextMenu`, `TreeView`, `FormField`, `Textarea`, `RadioGroup`, `Slider`, `Stepper`, `Toolbar`, `Separator`, `AreaChart`, and `RadialProgress`.

## Major enhancement

`DataTable` now supports sorting, selection, select-all, striping, sticky headers, and accessible captions without removing its 0.1.x API.

## Demo

Use the lower-right demo switcher to move between:

- **Dashboard** — the redesigned operations command center.
- **Component Lab** — interactive examples of the expanded component library.
